拖拽已排商品：重叠比例决定「对调 / 插入 / 普通移动」

重叠率 = 拖动虚影与某个商品的相交面积 ÷ 两者中较小方块的面积（方块含价签）。阈值仍是你定的 50% / 20%。
怎么算重叠率
判定顺序（建议）
  1. 同时压住同一行相邻的两个商品，且各自重叠率 > 20% → 插入 到它们之间。（新增这一条，原因见下方对比）
  2. 否则取重叠率最大的那个商品 T：
    ≥ 50% → 对调：A、T 交换，各自左边缘对齐到对方原位再吸附孔位；对调后与邻居冲突则拒绝。
    20–50% → 插入 到 T 之前或之后（虚影中心在 T 左半边就插在前面）。
    ≤ 20% → 普通移动：和现在一样吸附孔位，有冲突就弹回。
  3. 插入的后移：插入点之后的同行商品整体右移「A 宽 + 左右间距」，彼此间距不变；超出本节右边的末尾商品换到下一行左侧空位（只找空位，不推下一行的商品）。
  4. 拒绝：只在本节内后移或换行，不溢到相邻的节；放不下（已是最后一行、下一行没有空位）就整次拒绝，A 回原位。
为什么要加第 1 条：同宽商品紧挨着排时，原规则的插入区太窄
