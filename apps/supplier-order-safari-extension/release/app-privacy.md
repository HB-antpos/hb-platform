# App Privacy 申报

采用保守申报，不用于跟踪，不用于广告，不采集位置，不接入第三方分析 SDK。

| 数据类型 | 用途 | 与用户关联 | 跟踪 |
| --- | --- | --- | --- |
| Contact Info → Email Address | App Functionality | 是 | 否 |
| Identifiers → User ID | App Functionality | 是 | 否 |
| Other Data → 内部采购、销售与供应商商品业务数据 | App Functionality | 是 | 否 |
| Other Data → 供应商分类数据（分类名称、分类页地址、分类页上的商品货号、采集时间） | App Functionality | 是 | 否 |

账号密码只在 Hot Bargain 网站完成认证；扩展不收集、读取或保存账号密码与网站 Cookie。网站通过一次性授权码向扩展签发短期访问令牌，该令牌仅保存在浏览器会话存储中。门店选择与扩展设置的处理方式以公开隐私政策为准。

1.5.0 起的供应商分类采集只在用户已授权的供应商网站读取面包屑、页面标题、分类导航与分页链接以及分类页上的商品货号，回传“分类路径 + 货号 + 页面地址 + 采集时间”到 Hot Bargain 后台，与当前登录员工账号关联，用于整理 Hot Bargain 商品的供应商分类；不读取价格、供应商账户、订单、表单内容或 Cookie，不用于跟踪或广告。主动“采集全部分类”仅在用户点击后于其打开的供应商标签页内限速运行，不申请新增权限。扩展本地只保留 6 小时的去重哈希与最近一次采集摘要。
