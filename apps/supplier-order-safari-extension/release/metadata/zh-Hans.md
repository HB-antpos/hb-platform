# HB Supplier Order

副标题：供应商订货与销售洞察

HB Supplier Order 面向经授权的 Hot Bargain 员工，在 iPhone 和 iPad 的 Safari 供应商商品页面中提供订货辅助信息。

使用 Safari 扩展可以：

- 查看供应商商品的内部采购记录；
- 查看授权门店的销售记录和平均售价；
- 识别供应商热销商品与订货优先级；
- 从 Safari 或 Hot Bargain 订货门户打开完整助手。

本应用需要现有且已授权的 Hot Bargain 账号，不提供公开注册，不会自动向供应商下单，也不会代替用户作出采购决定。

本应用仅面向澳大利亚地区的 Hot Bargain 授权员工与采购人员，并仅支持 iPhone 和 iPad。

关键词：供应商,订货,采购,销售,库存,商务

## 1.6.0 更新内容

- 商品按钮新增「去年同期」一行：显示本店去年同一星期几起算、未来 30 天（或 60 天）的销量，订货前可直接对照；去年此时本店没有销售数据时不显示这一行。
- 助手新增「去年同期」30 / 60 天开关，切换立即生效；并新增「上次订货 / 至今销量 / 去年同期」对照卡片。
