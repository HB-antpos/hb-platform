# HB Supplier Order

副标题：供应商订货与销售洞察

HB Supplier Order 面向经授权的 Hot Bargain 员工，在 iPhone 和 iPad 的 Safari 供应商商品页面中提供订货辅助信息。

使用 Safari 扩展可以：

- 查看供应商商品的内部采购记录；
- 查看授权门店的销售记录和平均售价；
- 识别供应商热销商品与订货优先级；
- 从 Safari 或 Hot Bargain 订货门户打开完整助手。

本应用需要现有且已授权的 Hot Bargain 账号，不提供公开注册，不会自动向供应商下单，也不会代替用户作出采购决定。

本应用仅面向澳大利亚地区的 Hot Bargain 授权员工与采购人员，并仅支持 iPhone 和 iPad。

关键词：供应商,订货,采购,销售,库存,商务

## 1.5.0 更新内容

- 浏览受支持的供应商分类页时自动记录供应商分类，让 Hot Bargain 商品可以按各供应商自己的分类整理；可在助手中按供应商关闭。
- 助手新增“采集全部分类”：在当前打开的供应商网站内逐个分类限速读取，显示进度，并可随时中止。
- 若 iOS 挂起了供应商标签页，返回该标签页点击“继续”即可从中断处接着采集，读取失败的分类可“重试失败”。
